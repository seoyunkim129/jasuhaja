# 원정 자유수영 찾기 — 마포구 데이터 기준

확인일: 2026-09-19

## 목표

성인이 당일 방문해 자유수영할 수 있는 수영장을 한눈에 찾는다. 시설 이름에 `구민체육센터`가 들어가는지만 보지 않고, 실제 수영장 보유 여부와 일일입장 가능 여부를 각각 확인한다.

## 이번에 확인한 내용

- 마포구 후보 6곳을 `수영장.csv`에 기록했다.
- 반복되는 시간표는 `자유수영시간.csv`로 분리했다.
- 시설 위치는 TMAP 검색 결과로 확인했다.
- 시간표는 `공식확인`, `부분확인`, `참고정보`, `전화확인필요`로 구분했다.
- 현재 공식 일일입장 시간표와 요금까지 확인된 곳은 마포아트센터다.

## 중요한 정정

`마포구민체육센터`라는 특정 시설에는 현재 수영장이 없다. 이는 구민체육센터 전체에 수영장이 없다는 뜻이 아니다. 다른 자치구로 확대할 때 구민체육센터는 계속 우선 조사하되, 이름만으로 포함하지 않고 공식 시설 안내를 확인한다.

마포365구민체육센터 역시 건립 과정에서 수영장 계획이 사우나로 변경된 것으로 마포구의회 회의록에서 확인된다.

## 포함 기준

1. 마포구 안에 실제 수영장이 있다.
2. 성인 자유수영 또는 일일입장이 확인된다.
3. 어린이 전용·어린이 중심 수영장은 제외한다.
4. 공식 시간표가 없더라도 자유수영 가능성이 확인되면 후보로 남기고 `전화확인필요`로 표시한다.

## 제외한 시설

| 시설 | 제외 이유 |
| --- | --- |
| 마포구민체육센터 | 공식 시설 현황에 체육관·볼링장은 있으나 수영장은 없음 |
| 마포365구민체육센터 | 수영장 계획이 사우나로 변경됨 |
| 아이월드 마포센터 | 어린이 수영 중심이라 서비스 대상에서 제외 |
| 마포주민편익시설 | 공식 프로그램에 사우나·헬스·생활체육은 있으나 수영장 없음 |

## 데이터 사용 원칙

- 화면에서는 `공식확인` 시간표를 가장 먼저 보여준다.
- `부분확인`과 `참고정보`에는 반드시 방문 전 확인 안내를 표시한다.
- 시간표와 요금은 변동될 수 있으므로 각 행에 출처와 확인일을 유지한다.
- 향후 네이버 카페 후기는 운영 정보의 근거가 아니라 분위기·혼잡도·시설 상태를 보충하는 용도로만 사용한다.
