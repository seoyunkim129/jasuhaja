## 한 줄 요약

손으로 하던 수영장 시간표 갱신을 "매주 로봇이 공식 페이지 8곳을 확인 → 바뀐 곳만 AI가 글·공지 이미지를 읽어 표로 → 지금 시간표와 비교한 수정안 → 사람이 승인해야 반영" 구조로 만들었다. AI가 공지 이미지에서 시간표에 없던 회차 1건을 찾았고, 내가 원본 이미지와 대조해 승인한 뒤 반영했다.

## 8곳 모델 비교 (2026-11-22, 페이지당 1회)

기준은 지금 `자유수영시간.csv`다. 내가 그날 다시 검수한 정답표가 아니어서 **정답률이 아니라 일치율**이다. "칸"은 요일 하나 × 회차 하나(월~금 08:00 = 5칸).

| | Claude Sonnet 5.5 | Gemini 3.5 Flash |
| --- | --- | --- |
| 운영 중 5곳에서 읽은 칸 | 99 | 98 |
| CSV 93칸 중 찾음 | 93 (100%) | 93 (100%) |
| CSV에 없는데 읽음 | 6칸 | 5칸 |
| 요금 일치(공식 확인값만) | 89/101 (틀린 값 0, 12칸 비움) | 101/101 |
| 8곳 걸린 시간 | 62.4초 | 102.5초 |
| 8곳 추정 비용 | $0.200 | $0.237 |

- 휴관 2곳(아현, 서부여성)은 두 모델 모두 휴관으로 읽었다. 시립목동청소년센터는 공식 페이지에 시간표가 없어 Claude는 "확인불가", Gemini는 "운영·회차 0"으로 답했다.
- CSV에 없는데 읽은 것: Claude는 양천구민 13:00~13:50 "(수영불가/유아풀)" 회차, Gemini는 양천구민 월 회비 프로그램(자유수영20A, 36,000원)을 일일 회차로 적었다. 양천구민 13시 회차의 성인 이용 여부는 사람 확인이 필요해 반영하지 않았다.
- 비용은 토큰×공개 가격 추정이다. Gemini 가격은 공식 표가 아닌 가격 비교 사이트 값이고, 무료 등급 청구 여부는 확인하지 못했다. 오늘 두 번 돌린 합계는 Claude 약 $0.31, Gemini 약 $0.40(추정).
- 어느 모델을 매주 로봇에 쓸지는 이 1회 결과로 정하지 않았다. 지금 워크플로는 Claude로 되어 있다.

## 공공데이터포털 MCP 연결

- **언제**: 2026-10-14 (검색용 연결). 수영장업 API 키 발급·호출 확인은 10-14.
- **무엇에 쓰나**: (1) Claude Code에서 대화하며 공공데이터를 검색하는 용도(MCP, 키 불필요). (2) 행정안전부 수영장업 API(전국 1,902곳)로 **민간 수영장의 개업·폐업을 확인**하는 용도. 마포·양천은 민간 4곳만 나온다. 구민체육센터 같은 공공시설은 이 인허가 대상이 아니다.
- **왜 그 방식을 골랐나**: 정부가 만든 MCP 서버는 없고 개인·회사가 만든 도구뿐이라, 후보 3개를 "인증키가 어디로 가는지"로 비교했다. 검색은 키 없이 원격으로 하고, 키가 필요한 호출은 내 PC에서 포털로 직접 보내는 datagokr를 골랐다. 키가 드는 로컬 서버는 설치하지 않았고, 수영장업 API는 스크립트 없이 직접 호출로만 확인했다.
- **한계**: 공공데이터에 자유수영 시간표는 없다. 자동 갱신 로봇에는 아직 연결하지 않았다. 내 목록의 미진수영장 주소와 공공데이터 "미진어린이수영장" 주소가 달라 확인이 필요하다.

## 남은 것

1. 시립목동청소년센터가 GitHub 서버에서 403(10-14에는 200, 같은 날 내 PC에서는 열림). 원인 확인 필요. 지금은 로봇이 이슈로 알린다.
2. AI 요약을 붙이려면 저장소 Secrets에 `ANTHROPIC_API_KEY` 넣기, "Actions가 PR 만들기 허용" 켜기. 그 전까지 AI 요약·PR 경로는 GitHub에서 확인되지 않은 상태다.
3. Qwen: 알리바바 국제판 계정에서 모든 대화·이미지 모델이 403 `AccessDenied.Unpurchased`(10-14 ~ 11-22). 해결되면 같은 스크립트로 비교만 돌리면 된다.
4. 양천구민 13:00 회차, 미진수영장 주소는 사람이 확인.
5. 모델 비교를 정답률로 말하려면 CSV를 내가 다시 검수해야 한다.

## 자소서에 쓸 때 주의

- "몇 주째 자동으로 돌고 있다"고 쓰지 않는다. 지금은 **"매주 월요일 돌도록 GitHub에 올렸고, 수동으로 1회 실행해 7곳 변화 없음·1곳 접속 실패 알림을 확인했다"**가 사실이다. 로봇이 수정안 PR을 연 적은 아직 없다.
- "정확도 100%"라고 쓰지 않는다. **"기존 시간표 93칸을 두 모델 모두 다시 찾았다(일치율)"**가 사실이고, 기준 시간표를 다시 검수한 것은 아니다.
- AI가 찾은 변경은 **1건**(신석 화·목 11:00 한시 회차)이다.
- 세 모델 비교가 아니라 **두 모델 비교**다. Qwen은 시도했지만 계정 문제로 못 돌렸다.
- 쓸 수 있는 한 문장: "손으로 하던 시간표 갱신을, 로봇이 바뀐 곳을 찾고 AI가 이미지 공지까지 읽어 수정안을 쓰고 제가 승인하는 흐름으로 만들었습니다. AI가 공지 이미지에서 시간표에 없던 회차를 찾았고, 두 모델을 8곳에 돌려 비교하다가 요금이 틀린 원인이 모델이 아니라 제 전처리였다는 것을 원문 대조로 잡았습니다."
