# 후기 분석 비교 실험

## 목적

같은 네이버 카페 검색 요약문을 대상으로 키워드 방식과 Transformer 방식의 추출 결과를 비교하고, 포트폴리오에 최종 방식의 선택 근거를 남긴다.

## 최소 평가 기준

평가 항목은 혼잡 여유도, 시설 쾌적도, 수영 환경, 가성비 네 가지다. 각 항목은 `긍정 / 중립 / 부정 / 관련 없음`으로 판정한다. 한 문장에 여러 항목이 있으면 항목별로 따로 판정한다.

예시:

> 수질은 좋은데 샤워실은 좁고 사람이 많았다.

- 수영 환경: 긍정
- 시설 쾌적도: 부정
- 혼잡 여유도: 부정
- 가성비: 관련 없음

## 비교 대상

| 방식 | 역할 | 장점 | 한계 |
| --- | --- | --- | --- |
| 키워드 | 빠른 기준선 | 무료, 빠름, 근거가 명확함 | 문맥·부정 표현에 약함 |
| Transformer zero-shot | 항목·감성 동시 분류 | 새 라벨로 실험하기 쉬움 | 모델 비용, 한국어 도메인 정확도 검증 필요 |
| Sonnet/Opus 보조 라벨 | 최소 정답표와 키워드 후보 생성 | 복합 문장 해석에 강함 | API 비용, 결과 재현성, 사람 검수 필요 |

## 성공 기준

1. 시설별 서로 다른 관련 후기 3개 이상 확보
2. 사람이 검수한 표본과 항목 판정 일치율 기록
3. 긍정·부정뿐 아니라 `관련 없음`을 잘 거르는지 확인
4. 대표 근거 문장을 원문 링크와 함께 제시
5. 비용과 실행 시간을 함께 기록

## 실행

```text
npm run analyze:reviews
```

`HF_TOKEN`이 없으면 키워드 기준선만 실행한다. 토큰이 있으면 Hugging Face zero-shot 모델 결과도 같은 결과 파일에 추가한다. 결과는 `analysis/results/latest.json`과 `docs/후기분석-비교.md`에 저장한다.

## 주의

네이버 API가 제공하는 것은 카페 원문 전체가 아니라 검색용 제목과 요약문이다. 따라서 결과는 `카페 원문 전체 평가`가 아니라 `검색 요약문 기반 후기 신호`라고 표시한다.
