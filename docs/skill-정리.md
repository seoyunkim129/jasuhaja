# 물때 프로젝트 — 사용한 Claude Code 스킬 정리

작성일 2026-09-05 · 프로젝트 `물때` (수영장·다이소가 걸어서 가까운 집 찾기)

---

## 1. 스킬이란

Claude Code에 "이런 일은 이렇게 해라"를 미리 담아둔 설명서 묶음이다. 설치해두면 대화 중에 필요할 때 Claude가 알아서 꺼내 쓴다. 매번 사용법을 설명할 필요가 없어진다.

---

## 2. 출처 — NomaDamas / k-skill

한국 서비스 전용 스킬 모음. 국내 공공 API와 사이트를 다룬다.

- 저장소: https://github.com/NomaDamas/k-skill
- 스킬 개수: **131개**
- 라이선스: MIT

### 설치 명령어

```bash
# 하나만 설치
npx --yes skills add NomaDamas/k-skill --skill real-estate-search -g

# 전부 설치
npx --yes skills add NomaDamas/k-skill --all -g
```

`-g`는 전역 설치. 내 컴퓨터 전체에서 쓸 수 있고, 프로젝트 저장소에는 아무것도 안 들어간다.

### 설치 위치

```
~/.agents/skills/<스킬이름>
  └─ ~/.claude/skills/<스킬이름>   (심볼릭 링크로 연결)
```

> **주의 1** — 설치 후 `Failed to install 1 · PromptScript` 라는 빨간 메시지가 떠도 정상이다. PromptScript라는 다른 도구용 설치가 안 됐다는 뜻이고, Claude Code 쪽은 잘 설치된 것이다.
>
> **주의 2** — 설치해도 **새 대화를 열어야** 스킬이 인식된다.

## 3. 실제로 설치해서 쓴 스킬

### `real-estate-search`

| 항목 | 내용 |
|---|---|
| 하는 일 | 한국 부동산 실거래가·전월세 조회 |
| 데이터 출처 | 국토교통부(MOLIT) 실거래가 신고 데이터 |
| 지원 유형 | 아파트 / 오피스텔 / 연립다세대 / 단독다가구 / 상업업무용 |
| API 키 | **불필요** |
| 기반 | tae0y의 real-estate-mcp |

**물때에서 쓴 이유** — `danji.csv`의 단지 20개가 전부 손으로 넣은 가짜 데이터였다. 특히 가격이 그랬다. 원래 기획서에도 데이터 출처를 "국토부 실거래가"로 적어뒀는데, 그 출처가 그대로 스킬로 있었다.

**결과** — 강서구·양천구 2026년 3월~9월 실거래 **4,585건**을 받아 단지 **772개**를 추려냈다.

## 4. 겪은 문제와 해결

### 문제 — 스킬의 프록시 서버가 죽어 있었다

```
https://k-skill-proxy.nomadamas.org  →  HTTP 530 (error code 1033)
```

스킬은 기본적으로 이 프록시를 거쳐 데이터를 받는데, 서버 자체가 응답하지 않았다.

### 해결 — 국토부 원본을 직접 호출

스킬 안에 들어있던 `nationwide_daily_report.py` 코드를 읽어보니, 프록시를 안 거치고 국토부 실거래가 사이트에 직접 붙는 방법이 들어 있었다. **API 키도 필요 없었다.** 이 방식을 강서구·양천구만으로 좁혀서 다시 만들었다.

```
https://rt.molit.go.kr/pt/xls/ptXlsCSVDown.do
지역코드 — 강서구 11500 · 양천구 11470
응답 형식 — CP949 인코딩 CSV
```

> **배운 점** — 스킬이 안 돌아가도 그 안의 코드를 읽으면 우회로가 보인다. 스킬은 블랙박스가 아니라 그냥 읽을 수 있는 파일 묶음이다.

## 5. 물때에 쓸 만한 다른 스킬

| 스킬 | 쓸모 | 우선순위 |
|---|---|---|
| `real-estate-search` | 국토부 실거래가 | ✅ 사용 중 |
| `housing-official-price` | 공동주택 공시가격 | 검토 |
| `building-register-search` | 건축물대장 (준공년도·세대수) | 검토 |
| `daangn-realty-search` | 당근 매물 — "매물 보러 가기" 링크 연결 | 검토 |

### 이름에 속기 쉬운 스킬 두 개

**`daiso-product-search`** — 다이소가 들어가 있어 끌리지만, **매장 찾기가 아니라 "그 매장에 이 물건 재고 있나" 확인용**이다. 물때가 필요한 건 매장 위치이고, 그건 TMAP이 이미 한다.

**`kakao-map`** — POI 검색과 좌표 변환은 되지만 **도보 경로·도보 시간은 지원하지 않는다** (자동차 길찾기만). 물때의 핵심이 "걸어서 몇 분"이라 TMAP을 대체할 수 없다.

> **결론** — TMAP은 그대로 두고, 데이터 쪽만 스킬로 보강하는 구조가 맞다.

---

## 6. 스킬을 고를 때 기준

1. **이름만 보고 고르지 않는다.** `daiso-product-search`처럼 이름과 실제 기능이 다른 경우가 있다. `SKILL.md`를 먼저 읽는다.
2. **이미 되는 걸 대체하지 않는다.** TMAP으로 잘 되던 도보 시간을 굳이 다른 걸로 바꿀 이유가 없었다.
3. **필요한 것만 설치한다.** 131개를 다 깔면 로또·야구·사주까지 딸려온다.
4. **API 키가 필요한지 확인한다.** k-skill은 대부분 프록시를 써서 키가 없어도 된다.

---

## 7. 한 줄 요약

가짜 데이터로 만든 화면을, 스킬 하나로 국토부 실거래가에 연결했다. 스킬 서버가 죽어 있어서 스킬 안의 코드를 읽고 국토부에 직접 붙는 방식으로 우회했다.
