# 물때 — 디자인 브리프

## 누구를 위해

**이사를 준비하는 사람.** 아직 집을 안 정했고, 여러 동네·단지를 놓고 비교하는 중이다.

## 어떤 상황에서

부동산 앱에서 역세권·학군은 쉽게 걸러지는데, "여기서 수영 다닐 수 있나", "다이소가 가까운가" 같은 **생활 조건**은 앱마다 하나씩 직접 찍어봐야 한다. 그게 번거로워서 물때를 켠다.

## 무엇을 끝내야 하는지

후보 단지 몇 개를 놓고, **"여기는 살 만하다 / 아니다"를 몇 분 안에 판단**할 수 있어야 한다. 판단 재료는 실거래가(진짜 얼마인지)와 생활 시설 도보 거리(진짜 걸어서 갈 수 있는지) 두 가지.

## 가장 중요한 기능

**국토부 실거래가 + 수영장·다이소 도보권 필터.** 이게 없으면 물때는 그냥 평범한 지도 앱이다.

시설 직접 추가(GS25, 스타벅스 등)는 **부가 기능**으로 내린다. 이사 준비자에게 "매일 가는 편의점"은 판단에 크게 영향을 안 준다 — 있으면 좋지만 없어도 결정을 못 내리진 않는다. 나중에 우선순위가 남으면 붙인다.

## 성공 기준

- 후보 단지를 지도에서 눌렀을 때, **실거래가와 도보 시간이 한 화면에 같이** 보인다
- 조건(도보 5/10/15분, 주거형태, 자치구)을 바꾸면 후보가 **바로 걸러진다**
- 실거래가가 가짜가 아니라 **국토부 신고 데이터 그대로**다 (이미 됨)

## 지금 코드와 안 맞는 부분 (참고용)

최근 작업 방향이 "내 주변 시설 한눈에 보기"로 한 번 바뀌면서 시설 추가 기능이 화면 앞쪽에 크게 자리잡았다. 이 브리프대로면:

- 시설 추가 UI는 그대로 두되, **필터 바보다 아래·작게** 내리는 게 맞다
- 지도 첫 화면의 강조점은 **주황 핀(조건 통과 단지)**이어야 한다
- `index.html`의 매물 검색 링크(네이버 검색)는 이 브리프에서 오히려 핵심에 가깝다 — 나중에 실제 매물 사이트 링크로 강화할 만하다
