# 자수하자 — 디자인 브리프

갱신: 2026-09-27. 기존 이사·단지·다이소 중심 브리프를 현재 자유수영 서비스 기준으로 교체했다.

## 사용자와 목적

마포구·양천구의 성인 자유수영 이용자가 원하는 날짜·시간에 갈 시설을 비교하고, 시간·요금·규격을 확인한 뒤 길찾기로 이동한다. 지역 확대보다 현재 시설 정보의 정확성과 선택 편의가 우선이다.

## 정보 우선순위

1. 지역·날짜·시간 검색과 조건 부합 결과 수
2. 시설 이름, 선택일 시간표, 그 요일의 요금
3. 길이·레인·수심, 정보 출처와 확인 한계
4. 길찾기와 전화·운영처 안내
5. 혼잡·시설/샤워실·수질 후기

웹캠 게임은 유입 경로다. 본 사이트 ↔ 게임 → 수영장 지도 연결을 유지하되 검색을 가리지 않는다.

## 정렬과 신뢰도

- 선택 시간에 등록 시간표가 겹치는 시설 우선, 같은 상태에서는 선택한 요일의 등록 회차가 많은 순, 동률은 이름순.
- 시작·종료 시간이 모두 있는 중복되지 않는 구간만 센다. 긴 연속 운영 구간도 1개다. 회차 수는 운영시간 길이·빈자리·인원 수가 아니다.
- 확인 필요와 해당 시간 회차 없음은 뒤에 놓고 조건 부합 수와 전체 수를 구별한다.
- 시간표 미확인은 휴무가 아니다. 공휴일·임시휴관은 별도 확인이 필요하다.
- 공식 시간·요금·규격과 외부 참고·후기를 항목별로 구분한다. 공통 개장시간과 자유수영 문구의 결합은 세부 회차·휴식시간 확정으로 설명하지 않는다.
- 외부 안내를 읽은 날짜는 운영처의 정보 갱신일과 다르다. 충돌하는 자료는 확정 시간표로 채우지 않는다.
- 요금은 선택 요일 기준. 다른 요일 값만 있으면 '다른 요일 참고' 표시.

## UI와 성공 기준

- 검색이 주 행동, 게임·후기는 보조 행동이다.
- 같은 요일을 한 번 쓰고 여러 시간을 묶는다. 핵심 숫자와 보조 설명의 위계를 나눈다.
- 방문 판단을 좌우하는 경고를 작은 회색 글씨에 맡기지 않는다.
- 구·날짜·시간·검색 4단계로 결과 비교, 상세 또는 지도는 카드에서 각각 1회 이동한다. 입력 단계 수이며 달력 조작까지 센 실제 클릭 수는 아니다.
- 토요일 마포아트센터에 평일 요금이 나오지 않고, 같은 조건의 시설은 당일 등록 회차가 많은 순이어야 한다.
