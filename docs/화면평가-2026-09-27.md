# 물때 화면 평가 — 2026-09-27

대상: https://mulddae-cyan.vercel.app/ 수정 전 배포 화면과 현재 코드. 약 724×680 브라우저의 상단·카드 영역을 직접 확인했다. 휴대폰 실기기 검증은 하지 않았다.

**마포·양천의 성인 자유수영 이용자가 원하는 날짜·시간에 갈 수영장을 비교하고 길찾기로 이동하는 화면**이다. 기존 디자인 브리프는 이사·다이소 기준으로 남아 있어 현 서비스 기준으로 갱신했다.

## UI

- 색: 녹색이 공식 확인·가격·주 버튼에 함께 쓰이고 후기 가격도 같은 녹색이라 신뢰도 구분이 약하다.
- 글꼴: 안내·출처 CSS에 10~13px가 많아 방문 조건이 제목보다 지나치게 작다. 대비 비율은 측정하지 않아 WCAG 통과·실패를 단정하지 않는다.
- 간격: 현재 폭에서 2열 카드가 유지돼 시간 칩·버튼 문구가 줄바꿈되고 내용량 차이로 빈 공간이 생긴다.
- 위계: 큰 소개와 노란 게임 카드가 검색보다 먼저 보인다. 680px 높이에서 첫 시설 이름은 스크롤 전 거의 보이지 않는다.

## UX

구 → 날짜 → 시간 → 검색의 4입력 단계, 기본값 사용 시 검색 1회다. 실제 달력 클릭 수는 기기마다 다르다. 전체 시간표·규격은 상세 1회 추가, 지도는 카드에서 1회 이동한다. 기존 미확인 값은 문구만 있고 바로 연락할 경로가 없어 별도 검색이 필요했다.

## 30분 내 고칠 대상으로 고른 3개

각 10분은 국소 코드 수정 예상이며 자료 조사·전체 검증 시간이나 실제 소요시간을 뜻하지 않는다.

1. **1번 표시 로직**: 선택 요일 가격 사용, 해당 요일 값이 없으면 다른 요일 참고 표시, 미확인 값은 전화 연결. 최신 정보 자체를 10분 안에 확보한다는 뜻은 아니다. 로컬 반영.
2. **2번**: 이용 가능 → 확인 필요 → 회차 없음, 같은 상태는 당일 등록 회차 내림차순. 부합 수/전체 수·회차 수 표시. 로컬 반영.
3. **3번**: 가격 옆 공식·후기·외부 참고 표시, 상세에서 원문 링크 제공. 요금정보상태를 시간표 상태와 분리. 로컬 반영.

4·5번은 이번에 레이아웃까지 변경하지 않았다. 대규모 재설계나 외부 서비스 도입은 제안하지 않는다.
