## 클로드 피드백 (AI에게 내 화면 평가시키기 → 30분 내 해결 가능한 것만 우선 반영 완료)

### ① UI / UX 나눠서 평가

**UI (색·글꼴·간격·위계)**

- 색 팔레트(민트·주황·남색)는 두 화면 일관되게 씀
- 카드 안에서 **단지명이 16px/800굵기, 가격이 14px/700굵기** — 이름이 가격보다 크고 진함. 이사 준비자한테는 가격이 제일 중요한 판단 재료인데, 시각적으로는 부수 정보처럼 보임
- `map.html` 상단에 **intro 문단 → 필터 → 시설추가 바 → 결과 개수** 순으로 네 블록이 쌓여 있어서, 화면을 열자마자 보이는 건 지도가 아니라 텍스트

**UX (원하는 걸 몇 번 만에 하는지)**

- "이 조건에서 제일 싼 집 찾기" — **불가능**. 정렬 기능이 없어서 카드 10개를 하나씩 열어봐야 함
- "예산 6억 이하만 보기" — **불가능**. 필터는 도보시간·유형·자치구뿐이고 가격 범위 필터가 없음
- "지도에서 시설 하나 추가하기" — 입력창 클릭 → 이름 입력 → 버튼 클릭, 3번. 반면 "가격순으로 훑어보기"는 아예 경로 자체가 없음. **부가 기능이 핵심 기능보다 더 쉽게 되는 상태**

### ② 문제 5개 (심각한 순서)

1. **정렬 기능이 없다** — 후보 단지를 가격순·도보시간순으로 못 줄 세워서, 카드를 다 열어봐야 비교가 된다.
2. **가격 필터가 없다** — 유형·자치구·도보시간만 거를 수 있고, 브리프의 핵심 데이터인 실거래가는 필터에 아예 없다.
3. **카드에서 가격이 단지명보다 작고 흐리다** — 가장 중요한 결정 정보가 부수 정보처럼 보인다.
4. **map.html에서 시설추가 UI가 핵심 필터보다 주의를 더 끈다** — intro 문단과 시설추가 바가 필터·결과 개수 사이에 끼어 있어, 부가 기능이 화면 앞자리를 차지한다.
5. **map.html 첫 화면에서 지도 자체가 스크롤 없이 안 보인다** — intro+필터+시설바+개수, 네 블록이 위에 쌓여서 정작 봐야 할 지도가 화면 아래로 밀린다.

## 🧱 만난 에러와 해결

**① 배포 직후 URL이 로그인 화면으로 튕김**

Vercel이 처음 보여준 배포 URL(`mulddae-bwbm0zol4-...`)을 열면 `vercel.com/sso-api`로 리다이렉트됐다. 처음엔 배포가 잘못된 줄 알았는데, 알고 보니 **Vercel의 기본 배포 보호 기능**이었고, 프로젝트의 정식 도메인(`mulddae-cyan.vercel.app`)은 따로 있었다. 그 주소로 열자 바로 정상 작동.
→ **배운 것**: Vercel이 배포 직후 보여주는 URL이 항상 최종 주소는 아니다. Domains 탭에서 진짜 주소를 확인해야 한다.

**② `curl`로 확인한 `공통.js`가 404**

배포 후 파일이 다 잘 올라갔는지 `curl`로 하나씩 찔러봤는데 한글 파일명(`공통.js`)만 404가 떴다. 알고 보니 `curl`이 한글을 인코딩 안 하고 그대로 보내서 생긴 착시였다. **실제 브라우저는 `공통.js`를 `%EA%B3%B5%ED%86%B5.js`로 자동 변환**해서 요청하기 때문에 실제 사용자에겐 문제가 없었다.
→ **배운 것**: 도구로 확인한 결과가 항상 실제 사용자 경험과 같지는 않다. 도구의 한계인지 진짜 버그인지 구분해야 한다.

**③ GitHub CLI(`gh`) 자동 설치 실패**

`winget install GitHub.cli`로 한 번에 설치하려 했는데 관리자 권한 창에서 막혀 실패(`설치를 취소했습니다`). 대신 GitHub 웹사이트에서 직접 빈 저장소를 만들고, `git remote add` + `git push`로 우회했다.
→ **배운 것**: 자동화가 막히면 수동으로 한 단계만 거쳐도 나머지는 그대로 자동화할 수 있다.

**④ 문구 생성 기능에서 `\n`이 실제 줄바꿈으로 잘못 들어감**

"중개사에게 보낼 문구" 기능을 만들 때, 문자열 안에 `\n\n`(줄바꿈 이스케이프)을 넣었는데 파일에는 진짜 줄바꿈 문자가 그대로 박혀서 자바스크립트 문법 오류가 났다. 따옴표 문자열 대신 **백틱(템플릿 리터럴)로 바꿔서** 실제 줄바꿈을 그냥 써도 되게 고쳐 해결.
→ **배운 것**: 여러 줄 문자열은 이스케이프 문자로 억지로 이어붙이지 말고, 애초에 여러 줄을 그대로 쓸 수 있는 문법(백틱)을 쓰는 게 안전하다.
